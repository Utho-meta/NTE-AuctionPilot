# AuctionPilot（小吱视觉观察助手）

一个面向 Windows 的《异环》竞拍仓位识别与估价辅助工具。

程序只读取游戏画面并展示识别结果和估价建议，不会代替玩家点击、使用仪器或出价。

## 下载

[前往 Releases 下载最新版](https://github.com/Utho-meta/NTE-AuctionPilot/releases/latest)

当前版本：`v0.11.8`

请将压缩包完整解压到独立文件夹，再运行 `AuctionPilot.exe`。  
不要只单独复制 EXE，程序需要与目录内的 DLL、Assets、models 等依赖文件一起运行。

## 适用场次

- 推荐用于珊瑚场和真珠场。
- 当前估价模型不适用于低级场（海贝场）。

## 当前功能

- 原版客户端与云游戏客户端识别。
- 仓位轮廓、品质及部分藏品身份识别。
- 保守与激进两种估价策略。
- 达夫蒂尔助手。
- 中文离线 OCR。
- 暂停观察与桌宠提示。

## 隐私说明

正式版不会自动录制、保存或上传游戏画面和对局资料。

## 使用提醒

识别结果、估值范围和建议最高价仅供参考。程序不会自动操作游戏，也不保证最终收益。
