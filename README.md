# AuctionPilot（小吱视觉观察助手）

一个面向 Windows 的《异环》竞拍仓位识别与估价辅助工具。

程序只读取游戏画面并展示识别结果和估价建议，不会代替玩家点击、使用仪器或出价。

## 下载

[前往 Releases 下载最新版](https://github.com/Utho-meta/NTE-AuctionPilot/releases/latest)

当前版本：`v0.12.5`

请将 `AuctionPilot-v0.12.5.zip` 完整解压到独立的新文件夹，再运行 `AuctionPilot.exe`。

不要只单独复制 EXE；程序需要与目录内的 DLL、Assets、models、runtimes 等依赖文件一起运行。

## 适用场次

- 当前估价模型按珊瑚场和真珠场校准；海贝场不可直接套用。

## 当前功能

- 原版客户端与云游戏客户端识别。
- 仓位轮廓、品质及部分藏品身份识别。
- 保守与激进两种主模型估价策略。
- 阿德勒助手：在第 4 轮提供透明估价，并显示已确定价值与剩余红格均值估算。
- 埃德嘉助手：根据主轮廓、白绿蓝格与紫品占格信息建立金红基准估价。
- 达夫蒂尔助手：根据已知信息辅助排除组合方案。
- 公开金品数量会经多数确认后用于达夫蒂尔的金红拆分。
- 总金格与金品总价值信息可用于估算。
- 单格均、三格均、九格均提供红藏品存在性提示。
- 滚动扫描、扫描进度保持与第 4 轮结果锁定。
- 中文离线 OCR、暂停观察与桌宠提示。
- 可通过右键菜单手动录制对局。
- 发布包附带《红藏品单格价值参考》PDF。
- 另有独立的 AuctionPilot Arena 离线人机竞拍模拟器下载包。

## v0.12.5 更新重点

- 正式加入埃德嘉助手，并保持与阿德勒、达夫蒂尔互斥、默认关闭。
- 埃德嘉先按 6,874/格建立金红基准，再用已确认或明确候选的金红藏品修正估价范围。
- 保留 v0.12.4 已验证的主模型、滚动扫描、阿德勒和达夫蒂尔稳定性修复。
- 右键菜单中的专项助手调整为“达夫蒂尔→阿德勒→埃德嘉”，常用操作调整为“详细→录制→暂停→暂停快捷键”。
- 主程序与 AuctionPilot Arena 模拟器改为两个并列的独立下载包，避免用户在主程序目录内寻找模拟器。

## 录像与隐私

- 程序每次启动时录像默认关闭；只有右键选择“开始录制对局”后才会保存本地录像。
- 程序不会自动上传游戏画面、录像、设置或识别结果。
- 录像可能包含昵称、UID、聊天内容或资产信息，对外发送前请自行检查并遮挡隐私。
- 公开发布包不包含个人录像、用户设置、诊断记录或开发资料。

## 使用提醒

- 每轮从仓位顶部缓慢扫描到底部；显示扫描完成后再参考完整结果。
- 阿德勒助手在第 4 轮完整扫描后输出独立估价，并在第 5 轮沿用已锁定结果。
- 识别可能受到动画、光效、遮挡、画面压缩及游戏更新影响。
- 识别结果、估值和建议最高价仅供参考。程序不会自动操作游戏，也不保证最终收益。
