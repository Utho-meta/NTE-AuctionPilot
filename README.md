# AuctionPilot 四项目工具集

面向 Windows《异环》真珠、珊瑚拍卖的工具集，包含画面识别辅助、离线竞拍模拟、展柜搭配和版本分析报告。

主程序只读取游戏画面并展示识别结果与估价建议，不会代替玩家点击、使用仪器或出价。

## 开始使用

1. 将 ZIP **完整解压到新文件夹**，打开顶层的 `项目索引.html`。
2. 按索引进入需要的项目。主程序、Arena 已包含运行依赖，不要只复制单个 EXE。
3. 展柜和报告使用 Chrome 或 Edge 打开，可离线使用。
4. 保持四个项目的同级目录结构，Arena 和展柜中的“本期报告与视频”才能直接打开第四项目。

本次无需替换正在使用的主程序。旧安装、个人设置、录像和旧方案请保留。展柜迁移时先在旧版“导出方案”，再到新版“导入方案”；移动 HTML、换浏览器或清理缓存可能影响本地存档的读取。

## 01 · AuctionPilot 主程序

主程序观察游戏窗口，识别仓位轮廓、品质和部分藏品身份，提供估价建议、扫描进度、桌宠提示及手动录像功能。

合集中的 v0.12.12 Preview2 业务代码与功能沿用原版，附带运行依赖及第三方许可。Arena 的策略和模拟机制更新不代表主程序也作了相同修改。每轮请从仓位顶部缓慢扫描到底部，显示扫描完成后再参考结果。

## 02 · Arena 模拟器 v0.4.0 Preview12

- 修复第一轮仅用品质仪器时，桌宠普通估价仍显示“待扫描”的问题。
- 桌宠按主程序现有规则使用可见品质色块的位置估计仓深；色块仍为未知形状，不读取隐藏尺寸、身份或真实仓价。
- 普通估价与达夫蒂尔专用报价独立判断：未读紫总数时显示普通估价，达夫两档报价继续等待所需信息。

保留Preview11的均价截断修正，以及M1000的3×3占格、四块信息同页、轮廓开仓、逐件揭晓、品质延时、一键跳过和原有音效。

主程序及其桌宠计算源码、估价组件和模拟引擎保持原版；本次只修正模拟器向桌宠转换可见信息的方式。请完成或结束旧版正在进行的对局，关闭旧版后运行本版。

完整解压后打开 `02-Arena模拟器/更新说明.html`，可查看修正后桌宠报价预览及交互演示。

报告保留2026-11-13、Arena Preview5冻结模型的历史结果。当前模拟器已更正M1000尺寸和均价取整，可能影响估值及竞拍结果；尚未按这些修正重跑角色定榜，历史名次不作为本版重新验证的结论。本次只修正桌宠可见信息转换，模拟竞价引擎保持Preview11原版。

## 03 · 展柜搭配实验室 v0.4 Preview3

- 填写已有红藏品数量，生成**金珠最高、方斯最高、综合推荐**三种摆法。综合推荐指填满 120 格条件下金珠收益最高。
- 固定 15×8、最多 99 件、不旋转；自动推荐不超库存，金珠与方斯最高方案允许留空。
- **首次打开时库存和展柜均为空**；之后恢复本浏览器中自己保存的库存和摆放。生成推荐不会自动填入展柜，点击“应用方案”后才会替换摆放。
- 39 件红藏品使用实际仓库图片。家用电影机、乐园巧克力、守望者的收益已按实拍核对；仍待核实的旧数据保留标注，可在工具内修改。
- 支持拖动、撤销重做、收益修正、自定义藏品、JSON 备份和 PNG 导出。示例摆法需主动载入，不作为默认库存或实际推荐。
- 本期保留藏品数据和摆放算法，更新来源说明、报告入口及“你的展柜”“已有藏品 · 自动布局”标题。

这是本地离线工具，不读取账号或游戏窗口，也不上传库存和方案。收益计算以填写的数据为准，实际方斯到账还受游戏激励余额等条件影响。

## 本期验证与限制

1,885项界面与交互检查通过。手动品质开局覆盖两场、十角色共40个局面，其中6个旧版普通估价为空的局面恢复；相同问题场景的可见输入重建后同样恢复；不推断不可见藏品。品质位置估计与原主程序布局计算核对，空白画面、坐标缺失、轮廓揭晓替换色块及隐藏数据隔离检查通过。另有200个状态对照主程序计算，200项均价检查和32局打包程序均价回归通过。完整包解压启动通过。自动检查不等于长期实战验证。主程序880个文件、展柜4个文件及既有研究视频与上期逐字节一致。

此前的 1,196 次打包程序接口比对、60 局完整模拟、60 个金色核心实际启用用例、230 项 Arena 机制检查、35 项展柜浏览器检查和 6 项离线报告检查属于沿用的机制验证，不是此次重新完成的实战测试。

上述检查不等于长期实战验证。模拟参数不等于游戏服务器真实生成规则，特殊规则未全部覆盖；识别仍可能受动画、光效、遮挡、压缩和游戏更新影响。工具和报告不能保证现实对局收益，海贝场不可直接套用真珠、珊瑚模型。
