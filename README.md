# AuctionPilot（小吱视觉观察助手）

一个面向 Windows 的游戏画面观察与估价辅助工具。程序只读取游戏画面、展示仓位识别与估价建议，不会代替玩家点击、使用仪器或出价。

> 当前为封闭测试版。请勿公开转载、二次分发或用于商业用途。

## 下载

[前往 Releases 下载最新版](https://github.com/Utho-meta/NTE-AuctionPilot/releases/latest)

当前版本：`v0.10.2`

下载 `AuctionPilot-ClosedBeta-v0.10.2.zip` 后完整解压，再运行 `AuctionPilot.exe`。请勿直接在压缩包内启动。

## 当前功能

- 珊瑚场：读取竞拍轮次、公开信息、当前估价和仓位画面。
- 结合滚动轨迹拼接 `10×N` 仓位轮廓。
- 按“轮廓价＋金品溢价＋红品溢价”显示中心估值和可能范围。
- 识别红品及五件重尾金品的高价值风险。
- 真珠场影子观察：仅记录轮次、轮廓、品质、身份、当前估价和结算数据，不输出报价。
- 自动保留最近三场诊断资料，并整组淘汰更早的录像、事件和截图。

## 使用方法

1. 使用中文界面的游戏并进入大厅。
2. 启动 `AuctionPilot.exe`，无需管理员权限，也无需另装 .NET。
3. 珊瑚场出现滚动条时，从顶部连续翻到底部，让程序确认完整轮廓。
4. 如需切换观察模式，请在大厅右键桌宠操作；竞拍进行中不可切换。

## 环境说明

- 推荐 Windows 10/11，分辨率为 `1920×1080` 或 `2560×1440`、16:9。
- 双显示器下，建议先让游戏与桌宠位于同一显示器。
- 完全独占全屏可能覆盖普通置顶窗口，建议使用无边框全屏或窗口化模式。
- 测试版尚未购买代码签名证书，Windows 可能显示“未知发布者”。

## 隐私与问题反馈

诊断录像和截图可能包含游戏昵称、UID、资产数值等屏幕信息。请先退出程序，再自行检查并只提交与问题对应的 `auction-XXX-` 文件组。

详细说明见 [PRIVACY.md](PRIVACY.md)。问题可通过 GitHub Issues 反馈。
