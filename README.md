# AuctionPilot 四项目工具集

面向 Windows《异环》真珠、珊瑚拍卖的工具集，包含画面识别辅助、离线竞拍模拟、展柜搭配和版本分析报告。

主程序只读取游戏画面并展示识别结果与估价建议，不会代替玩家点击、使用仪器或出价。

## 开始使用

1. 将 ZIP **完整解压到新文件夹**，打开顶层的 `项目索引.html`。
2. 按索引进入需要的项目。主程序、Arena 已包含运行依赖，不要只复制单个 EXE。
3. 在资源管理器中双击 `展柜搭配实验室.exe`，会用默认浏览器打开页面。展柜也可直接打开 HTML，报告可离线查看。
4. 保持四个项目的同级目录结构，Arena 和展柜中的“本期报告与视频”才能直接打开第四项目。

请先关闭旧主程序，再从新解压目录启动。旧安装、个人设置、录像和旧方案请保留。如需沿用主程序设置，可将旧目录的 `auction-pilot.json` 复制到新主程序目录。展柜迁移时先在旧版“导出方案”，再到新版“导入方案”；移动 HTML、换浏览器或清理缓存可能影响本地存档的读取。

## 01 · AuctionPilot 主程序

主程序观察游戏窗口，识别仓位轮廓、品质和部分藏品身份，提供估价建议、扫描进度、桌宠提示及手动录像功能。

本期修复识别开始后浮窗跳回下方、局内拖动时回跳的问题。手动移动后会保留松手位置。程序内版本仍显示 v0.12.12 Preview2，请用 **2026-11-19** 的合集区分修订包。启动屏幕识别请运行 `AuctionPilot.exe`。Arena Preview14 是同包中的独立模拟器。

## 02 · Arena 模拟器 v0.4.0 Preview14

- 报价输入实时显示千位逗号，例如177777显示为177,777；支持键盘输入、粘贴、数字键盘、倍率与上轮出价。
- 四席报价动画结束后，未成交的对局自动进入下一轮；仍由玩家选择仪器并提交报价。跳过动画同样只推进一轮。
- 最后一件藏品的揭晓动画结束，即可点击右上角“下一局”；取消原有额外3秒停留，保留逐件揭晓与品质等待时间。

保留Preview13的仪器与桌宠适配、品质开局普通估价、均价截断规则、M1000的3×3占格、四块信息同页、轮廓开仓、一键跳过和原有音效。

本期 Arena 新增小吱启动图标，报价流程、估价和模拟引擎沿用 11 月 15 日的 Preview14。

完整解压后打开 `02-Arena模拟器/更新说明.html`，可查看输入与自动切轮预览及交互演示。

报告保留 2026-11-13 的 Arena Preview5 冻结模型结果。之后修正的 M1000 尺寸和均价取整尚未用于重跑角色定榜。本期调整浮窗拖动和启动入口，沿用既有研究视频与排名。

## 03 · 展柜搭配实验室 v0.4 Preview3

- 填写已有红藏品数量，生成**金珠最高、方斯最高、综合推荐**三种摆法。综合推荐指填满 120 格条件下金珠收益最高。
- 固定 15×8、最多 99 件、不旋转；自动推荐不超库存，金珠与方斯最高方案允许留空。
- **首次打开时库存和展柜均为空**；之后恢复本浏览器中自己保存的库存和摆放。生成推荐不会自动填入展柜，点击“应用方案”后才会替换摆放。
- 39 件红藏品使用实际仓库图片。家用电影机、乐园巧克力、守望者的收益已按实拍核对；仍待核实的旧数据保留标注，可在工具内修改。
- 支持拖动、撤销重做、收益修正、自定义藏品、JSON 备份和 PNG 导出。示例摆法需主动载入，不作为默认库存或实际推荐。
- 本期新增小吱图标的 Windows 启动入口，可以继续直接打开 HTML。沿用藏品数据和摆放算法。

这是本地离线工具，不读取账号或游戏窗口，也不上传库存和方案。收益计算以填写的数据为准，实际方斯到账还受游戏激励余额等条件影响。

## 04 · 版本分析报告 v1.0

解压后打开 `04-版本报告/index.html`，可观看约 4 分钟的 PPT 风格讲解视频，并阅读完整分析报告与打法速查。

- **视频**：用图表解释真珠、珊瑚角色与配装结论，配柔和普通话女声、中文字幕，右下角为日常装桌宠说话动作。
- **文档**：包含 HTML 分析报告、打法速查、讲解稿、字幕、主榜数据、匿名模拟汇总和版本清单。
- **适用口径**：2026-11-13 冻结标准局模型，全部出售、不计展柜，对应研究时的 Arena v0.4.0 Preview5。不能将拍卖定榜直接当作展柜收益排名。
- **结论边界**：区分游戏规则变化、模型修正和打法优化。本期是模拟与打法复核，不是游戏官方角色平衡公告；珊瑚场不宣称唯一冠军。

报告保留 2026-11-13 的 Arena Preview5 冻结模型结果。之后修正的 M1000 尺寸和均价取整尚未用于重跑角色定榜。本期调整浮窗拖动和启动入口，沿用既有研究视频与排名。

后续按版本保留报告、图表数据、视频、讲稿与字幕、匿名汇总，说明变化来源和适用范围。
